# Convenciones de etiquetas y nombres

Los formularios usan etiquetas `<label>` asociadas a sus controles mediante `for` e `id`. Los controles de selección deben mostrar valores existentes del sistema cuando la operación depende de un laboratorio, equipo, usuario o estado registrado. Los botones indican la acción que ejecutan y los errores se comunican mediante mensajes comprensibles.
