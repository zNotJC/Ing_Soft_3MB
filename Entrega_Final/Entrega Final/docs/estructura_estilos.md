# Estructura y estilos

- `proyecto/app/controladores/`: validación y coordinación de operaciones.
- `proyecto/app/modelos/`: acceso a datos y reglas de persistencia.
- `proyecto/app/vista/`: plantillas PHP de presentación.
- `proyecto/app/vista/navbar/`: parcial PHP compartido de navegación.
- `proyecto/app/nucleo/`: respuestas JSON, autenticación y componentes compartidos.
- `proyecto/app/rutas/`: despacho de recursos de la API.
- `proyecto/app/config/`: configuración de conexión.
- `proyecto/public/assets/css/`: hojas de estilo.
- `proyecto/public/assets/js/`: comportamiento del navegador.
